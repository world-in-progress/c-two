# @c-two/c2-mem-ffi

The TypeScript substrate is built from source with its matching native library and Node addon. Endpoint directory behavior is documented in the [lifecycle guide](../../../../../docs/reference/local-endpoint-lifecycle.md).

This package is the Node client of C-Two: a TypeScript facade and Node-API loader for the Rust `c2-mem-ffi` library, C/FFI ABI 10. The native library connects, performs the IPC handshake and runs the single reader and writer of each physical connection in Rust; it owns call records, shared-memory loans and their release, and the client domain's memory, file spill and call budgets. JavaScript passes request bytes in and receives local response buffers; it never reads a frame, handles a loan or constructs an OS object name.

The source build supports Linux and macOS shared libraries and Windows `c2_mem_ffi.dll`. The loader uses `dlopen` on Unix and Unicode `LoadLibraryExW` on Windows. Windows addon builds use the pinned development dependency `node-gyp` with Python and Visual Studio C++ build tools. A native run on each target is required to establish runtime support; the package contains the artifacts built for the current platform and architecture.

The addon targets Node-API 10. Use Node 22.14 or newer in the Node 22 line, or Node 24 or newer; earlier Node 22 releases expose Node-API 9. Build tools and consumers must both use a supported runtime.

`createNodeIpcConnector(options)` creates one native client domain, shared by every endpoint and reconnect it creates; its memory budget, file spill budget and outstanding call limit apply across reconnects. Options are `ipcRoot` or a captured `endpointContext` (not both), `addonPath`, `nativeSymbols` (a loaded ABI 10 addon or a test double), the domain limits `memoryBudgetBytes`, `fileSpillBudgetBytes` and `maxOutstandingCalls`, and the defaults `connectTimeoutMs` and `expectedServerIdentity`; an unknown option is rejected. The connector is an async function `connect(address, timeoutMs?, nativeOptions?)` that resolves to a native endpoint handle without opening a connection yet. The first `prepare` validates the route over IPC or relay. For HTTP(S) addresses, `nativeOptions.mode` selects `relay_aware` (default) or `explicit_relay`. The expected server identity option applies to direct IPC; the connector also carries `resolveEndpoint(address)`, `stats()` and `close()`. Domain limits accept non-negative safe integers or unsigned 64-bit bigints. `stats()` reads the client role without activating it. It reports nullable `memory` and `file_spill` cells and a `call_execution` snapshot. Identifiers and counters are decimal strings when present. Its `close` releases the domain's own reference; endpoints and calls already created keep their owners. Generated clients pass the connector to `createIpcEncodedTransport(address, { connect })`.

Addresses are logical `ipc://server-id` addresses. Rust resolves each one to a Unix socket or a Windows Named Pipe in the current user scope; `resolveLocalIpcEndpoint(address)` exposes the same resolver for diagnostics and does not treat a pipe endpoint as a filesystem path. `captureLocalIpcEndpointContext({ ipcRoot })` captures the endpoint configuration once, so later environment changes do not affect connectors created from it. A connect timeout is the remaining budget for the connection attempt, including the namespace gate, endpoint identity verification and the IPC handshake; without one the native five-second guards apply. On Windows the native server must have the matching TokenUser and at least Medium integrity.

A native endpoint's `prepare(route, contract, timeoutMs?)` connects and validates the complete route contract; `timeoutMs` bounds this preparation together with the endpoint's `connectTimeoutMs`, whichever is smaller, and zero expires at once. With `expectedServerIdentity`, every later acquisition must reach that server instance; without it, a call after the server ended acquires the route again at the same address and accepts a new instance. `connectionSnapshot(route)` reads, without I/O, the connection that the route's last preparation observed: its `connectionId`, server identity and `endReason`, or `null` before a preparation. A successful `dispatch` reports the target that this call was sent to, `{ path, serverId, serverInstanceId, connectionId }`, which can differ from the preparation when Core acquired the route again before sending. `beginCall(route, method, serverStream, timeoutMs)` starts a call before its input is encoded; the timeout is one absolute deadline for encoding, admission and the whole iteration, and `null` is unlimited. A call checks its native deadline around JavaScript encode/decode with `checkDeadline()`, reserves its input with `chargeInput`, sends it with `dispatch` and receives responses or stream items with `next`, one pending at a time. `cancel` and `close` submit stream cancellation without waiting; closing a dispatched unary call never cancels it. `observe(timeoutMs)` submits cancellation and waits for the original call record, returning `{ completed, error, completeItems }` where `completeItems` is a `bigint | null`; `null` waits without limit and `0` observes once. `deactivate` stops new calls on the endpoint while calls already sent finish, and `close()` asynchronously closes the endpoint after its calls and loans settle.

A response is a `NativeBuffer`, a `Uint8Array` over a local Rust-owned copy: the transport lease ended before JavaScript saw it. `release()` detaches the view before freeing the copy. Native failures surface as `C2NativeError`, whose `nativeDetails` carry the canonical code and name, details, and `transportPhase` (`pre_dispatch` or `dispatch_uncertain`); `C2NodeIpcConnectionError` reports invalid connector use and `C2MemFfiBindingError` a broken native load.

`loadBundledC2MemFfiNodeNativeSymbols()` loads the packaged native library and `resolveBundledC2MemFfiNodeNativeLibraryPath()` returns its path. `loadC2MemFfiNodeNativeSymbols(libraryPath)` accepts an explicit external library built with **ABI version 10**. The addon checks the native ABI before loading any other symbol, so an older library is rejected with a version error rather than a missing symbol. The addon, TypeScript facade and native library must be built as a matching set.

```bash
cargo fetch --locked --manifest-path ../../../../Cargo.toml
npm ci
npm test
npm run pack:check
```

`npm test` builds the TypeScript, Rust library and Node addon before running native tests, and compiles the generated TypeScript transport regression suite through `c2-codegen` (requiring a fetched `core/Cargo.toml` cache and `FASTDB_PAYLOAD_LINK_MODE=system` with `FASTDB_PAYLOAD_SYSTEM_LIB_DIR` pointing at the verified FastDB CoreSDK library directory when no local `.venv` or sibling FastDB build is present). `npm run pack:check` verifies the package file inventory and installs the exact local tarball into a separate ESM consumer, which checks types, bundled library loading and a verified IPC call to a native peer. The archive contains `dist/index.js`, `dist/index.d.ts`, the `.node` addon, the target native library, this README and `package.json`. This is a local package check, not a registry publication.

The scripts launch child JavaScript through `process.execPath`. TypeScript can be overridden using `TSC_JS` or `TSC`; Cargo can be overridden using `CARGO` or resolved through `CARGO_HOME`, the user's `.cargo/bin`, and then `PATH`. Windows builds require the target MSVC tools to be installed; `node-gyp` selects the matching Node headers and import library.

Portable FastDB adapters are composed separately from Core-generated artifacts and currently open owned payload copies. Holding a payload is a lifetime contract, not a claim of direct response-SHM construction or zero-copy decoding. See the [C ABI](../../../../../docs/reference/c-abi.md), the [configuration guide](../../../../../docs/reference/configuration.md) and the [lifecycle guide](../../../../../docs/reference/local-endpoint-lifecycle.md).

After preparing a route, submit a keyed unary operation with `endpoint.beginCall(route, method, false, timeoutMs, callId)`. A key is 1–128 ASCII letters, digits, underscores or hyphens. Keep it unique for the lifetime of the logical operation. When a keyed call fails with `transportPhase === "dispatch_uncertain"`, its error exposes `callId`. Use `await endpoint.queryCall(route, callId, timeoutMs)` to inspect the registration while a business call is running. Use `await endpoint.recoverCall(route, method, callId, timeoutMs)` to attach to the operation or replay its result. Release the returned native buffer after reading it. An unknown key gives `unknown` on query and `723 CallOutcomeUnknown` on recovery. Reconcile that state with the resource's durable record before deciding whether to submit another operation.

A recovery deadline bounds the caller's wait. If it expires after dispatch, the caller receives `715 CallDeadlineExceeded` with `transportPhase === "dispatch_uncertain"` and the original `callId`. The endpoint's `close()` waits for the recovery record to settle.

Prepare a route before calling `endpoint.openSubscription(route, topic, options, timeoutMs)`. The handle exposes the READY sequence as `startSeq: bigint`, supports async iteration, and returns owned local buffers that callers release explicitly. `cancel()` submits cancellation and `close(timeoutMs?)` observes the terminal receipt. A generated contract decodes deliveries and releases native buffers unless the caller chooses a held subscription. Pass the connector as `connect` to the generated relay transport to subscribe over Core.
