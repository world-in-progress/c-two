# @c-two/c2-mem-ffi

The TypeScript substrate is built from source with its matching native library and Node addon. Endpoint directory behavior is documented in the [lifecycle guide](../../../../../docs/reference/local-endpoint-lifecycle.md).

TypeScript facade and Node-API loader for the Rust `c2-mem-ffi` memory context. The native library owns backing names, pool incarnations, buddy generations, allocation, loans and release. JavaScript passes native block descriptors through unchanged; it does not implement a second allocator or construct OS object names.

The source build supports Linux and macOS shared libraries and Windows `c2_mem_ffi.dll`. The loader uses `dlopen` on Unix and Unicode `LoadLibraryExW` on Windows. Windows addon builds use the pinned development dependency `node-gyp` with Python and Visual Studio C++ build tools. A native run on each target is required to establish runtime support; the package contains the artifacts built for the current platform and architecture.

The addon targets Node-API 10. Use Node 22.14 or newer in the Node 22 line, or Node 24 or newer; earlier Node 22 releases expose Node-API 9. Build tools and consumers must both use a supported runtime.

`createNodeIpcConnect()` accepts logical `ipc://server-id` addresses. Rust resolves each address to a Unix socket or a Windows Named Pipe in the current user scope. `resolveLocalIpcEndpoint(address)` exposes the same native resolver for diagnostics. Neither helper treats a pipe endpoint as a filesystem path. The connector takes an optional remaining budget in milliseconds; the generated IPC transport derives it from its `connectTimeoutMs` option, one deadline across the native connection and the IPC handshake. Without it the native five-second guards apply.

Connections provide `write`, `readExactly` and a required, idempotent `close` that terminates pending reads and writes. Custom connectors must implement that contract; injected sockets must implement the native `pause` and `resume` operations. The connector factory's own `close` releases its endpoint snapshot and leaves existing connections usable.

The Node connection pauses input while no read needs more bytes. Low-level consumers exchanging large writes in both directions must also advance their reads. Generated clients receive replies while uploading a chunked request and close failed chunked exchanges before another call can reuse the stream. The next call reconnects with the same server and route identity requirements; failed calls are never replayed. Successful calls retain their connection. Idle prefetch is bounded by read demand; this does not impose a total memory limit on valid in-flight payloads or user-retained results.

Use `createBundledC2MemFfiNodeRuntime()` for generated clients. It exposes `connect`, `resolveEndpoint` and `close`. Each verified IPC connection carries its own native memory context, so generated clients take no separate SHM reader or writer. Native loading is deferred until an IPC operation, so creating a transport configuration for HTTP does not open local shared memory.

`loadBundledC2MemFfiNodeNativeSymbols()` loads the packaged native library. `resolveBundledC2MemFfiNodeNativeLibraryPath()` returns its path. `loadC2MemFfiNodeNativeSymbols(libraryPath)` accepts an explicit external library built with **ABI version 7**. The addon, TypeScript facade and native library must be built as a matching set: native ABI is checked before loading the remaining symbols, and older libraries are rejected. ABI 7 requires the complete endpoint-context API, including both connection symbols on every platform: the Unix descriptor entry and the Windows Named Pipe entry returning the verified pipe plus its pinned server process. Typed peer identity refusals surface as `IDENTITY_MISMATCH` (7); ordinary permission failures remain `PERMISSION_DENIED` (6), and other I/O failures remain `IO_ERROR` (5). The official connector retains those names in `C2NodeIpcConnectionError`; it does not reinterpret a refusal as an absent endpoint. On Windows the official `createNodeIpcConnect` connector opens sockets only through the addon's module-level verified connect, which re-validates the native context type tag; `createConnection`, `resolveEndpoint`, and `nativeSymbols` injections are rejected there at construction. Unix keeps its existing injection surface. TypeScript endpoint symbols must provide context capture; `C2MemFfiEndpointContextUnsupportedError` has been removed. Endpoint functions accept only the logical address, with no protocol selector. Credential `managed-v2` / `named-pipe` values describe formats, not selectable backends. Blocks carry `segmentIndex`, `generation`, `offset`, `byteLength`, `dedicated`, and a lossless `loanId: bigint`; buddy and dedicated blocks both have a positive generation and loan ID. A response is consumed once: the native copy into the caller's buffer ends the remote read and queues the release, and the connection's single writer sends it without waiting for the next call.

A memory context's `prefix` already carries a fresh process and pool incarnation; send it in the handshake, and after the metadata ACK pass the peer's prefix to `finishHandshake` (null disables response SHM). The handshake lists no segments: Rust opens each backing from the peer prefix, slot and generation when a descriptor arrives. A descriptor whose mapping fails is still released, and `discardResponse` releases a response that is never read.

```bash
npm ci
npm test
npm run pack:check
```

`npm test` builds the TypeScript, Rust library and Node addon before running native tests. `npm run pack:check` verifies the package file inventory and installs the exact local tarball into a separate ESM consumer. That consumer checks types, bundled library loading, a verified IPC call to a native peer and the `bigint` loan ID of an opaque request owner. The archive contains `dist/index.js`, `dist/index.d.ts`, the `.node` addon, the target native library, this README and `package.json`. This is a local package check, not a registry publication.

The scripts launch child JavaScript through `process.execPath`. TypeScript can be overridden using `TSC_JS` or `TSC`; Cargo can be overridden using `CARGO` or resolved through `CARGO_HOME`, the user's `.cargo/bin`, and then `PATH`. Windows builds require the target MSVC tools to be installed; `node-gyp` selects the matching Node headers and import library.

This package exposes C-Two memory ownership and byte transport only. Portable FastDB adapters are composed separately from Core-generated artifacts and currently open owned payload copies. Holding a payload is a lifetime contract, not a claim of direct response-SHM construction or zero-copy decoding.

Unix connectors establish connections through Rust `c2-local`, including directory-relative addressing for long roots. The N-API worker retains the captured context until completion; an owned descriptor is transferred to Node Socket or closed on disposal. Windows connectors open the TokenUser-scoped pipe through the verified native entry before sending. The native server must have matching TokenUser and at least Medium integrity; raw `createConnection`, `resolveEndpoint` and `nativeSymbols` options are rejected on Windows. Real captured native contexts remain injectable. The descriptor and process pin use the existing socket closure path. See the [configuration guide](../../../../../docs/reference/configuration.md) and [lifecycle guide](../../../../../docs/reference/local-endpoint-lifecycle.md).
