# @c-two/c2-mem-ffi

The TypeScript substrate is built from source with its matching native library and Node addon. Endpoint directory behavior is documented in the [lifecycle guide](../../../../../docs/reference/local-endpoint-lifecycle.md).

This package is the Node client of C-Two: a TypeScript facade and Node-API loader for the Rust `c2-mem-ffi` library, C/FFI ABI 8. The native library connects, performs the IPC handshake and runs the single reader and writer of each physical connection in Rust; it owns call records, shared-memory loans and their release, and the payload buffer budget. JavaScript passes request bytes in and receives local response buffers; it never reads a frame, handles a loan or constructs an OS object name.

The source build supports Linux and macOS shared libraries and Windows `c2_mem_ffi.dll`. The loader uses `dlopen` on Unix and Unicode `LoadLibraryExW` on Windows. Windows addon builds use the pinned development dependency `node-gyp` with Python and Visual Studio C++ build tools. A native run on each target is required to establish runtime support; the package contains the artifacts built for the current platform and architecture.

The addon targets Node-API 10. Use Node 22.14 or newer in the Node 22 line, or Node 24 or newer; earlier Node 22 releases expose Node-API 9. Build tools and consumers must both use a supported runtime.

`createNodeIpcConnector(options)` creates one native client domain, shared by every endpoint and reconnect it creates; its payload buffer budget is not reset by a new connection. Options are `ipcRoot` or a captured `endpointContext` (not both), `addonPath`, `nativeSymbols` (a loaded ABI 8 addon or a test double), the request policies `requestShmThreshold` and `requestChunkSize`, which the domain fixes for every connection, and the defaults `connectTimeoutMs` and `expectedServerIdentity`; an unknown option is rejected. The connector is a function `connect(address, timeoutMs?, nativeOptions?)` that returns a native endpoint, where `nativeOptions` may override only the connect timeout and the expected server identity, and carries `resolveEndpoint(address)`, `stats()` and `close()`. Its `close` releases the domain's own reference; endpoints and calls already created keep their owners. Generated clients pass the connector to `createIpcEncodedTransport(address, { connect })`.

Addresses are logical `ipc://server-id` addresses. Rust resolves each one to a Unix socket or a Windows Named Pipe in the current user scope; `resolveLocalIpcEndpoint(address)` exposes the same resolver for diagnostics and does not treat a pipe endpoint as a filesystem path. `captureLocalIpcEndpointContext({ ipcRoot })` captures the endpoint configuration once, so later environment changes do not affect connectors created from it. A connect timeout is the remaining budget for the connection attempt, including the namespace gate, endpoint identity verification and the IPC handshake; without one the native five-second guards apply. On Windows the native server must have the matching TokenUser and at least Medium integrity.

A native endpoint's `prepare(route, contract, timeoutMs?)` connects and validates the complete route contract; `timeoutMs` bounds this preparation together with the endpoint's `connectTimeoutMs`, whichever is smaller, and zero expires at once. With `expectedServerIdentity`, every later acquisition must reach that server instance; without it, a call after the server ended acquires the route again at the same address and accepts a new instance. `connectionSnapshot(route)` reads, without I/O, the connection that the route's last preparation observed: its `connectionId`, server identity and `endReason`, or `null` before a preparation. A successful `dispatch` reports the target that this call was sent to, `{ path, serverId, serverInstanceId, connectionId }`, which can differ from the preparation when Core acquired the route again before sending. `beginCall(route, method, serverStream, timeoutMs)` starts a call before its input is encoded; the timeout is one absolute deadline for encoding, admission and the whole iteration, and `null` is unlimited. A call reserves its input with `chargeInput`, sends it with `dispatch` and receives responses or stream items with `next`, one pending at a time. `cancel` and `close` submit stream cancellation without waiting; closing a dispatched unary call never cancels it. `observe(timeoutMs)` submits cancellation and waits for the original call record, returning `{ completed, error, completeItems }`; `null` waits without limit and `0` observes once. `deactivate` stops new calls on the endpoint while calls already sent finish.

A response is a `NativeBuffer`, a `Uint8Array` over a local Rust-owned copy: the transport lease ended before JavaScript saw it. `release()` detaches the view before freeing the copy. Native failures surface as `C2NativeError`, whose `nativeDetails` carry the canonical code and name, details, and `transportPhase` (`pre_dispatch` or `dispatch_uncertain`); `C2NodeIpcConnectionError` reports invalid connector use and `C2MemFfiBindingError` a broken native load.

`loadBundledC2MemFfiNodeNativeSymbols()` loads the packaged native library and `resolveBundledC2MemFfiNodeNativeLibraryPath()` returns its path. `loadC2MemFfiNodeNativeSymbols(libraryPath)` accepts an explicit external library built with **ABI version 8**. The addon checks the native ABI before loading any other symbol, so an older library is rejected with a version error rather than a missing symbol. The addon, TypeScript facade and native library must be built as a matching set.

```bash
npm ci
npm test
npm run pack:check
```

`npm test` builds the TypeScript, Rust library and Node addon before running native tests. `npm run pack:check` verifies the package file inventory and installs the exact local tarball into a separate ESM consumer, which checks types, bundled library loading and a verified IPC call to a native peer. The archive contains `dist/index.js`, `dist/index.d.ts`, the `.node` addon, the target native library, this README and `package.json`. This is a local package check, not a registry publication.

The scripts launch child JavaScript through `process.execPath`. TypeScript can be overridden using `TSC_JS` or `TSC`; Cargo can be overridden using `CARGO` or resolved through `CARGO_HOME`, the user's `.cargo/bin`, and then `PATH`. Windows builds require the target MSVC tools to be installed; `node-gyp` selects the matching Node headers and import library.

Portable FastDB adapters are composed separately from Core-generated artifacts and currently open owned payload copies. Holding a payload is a lifetime contract, not a claim of direct response-SHM construction or zero-copy decoding. See the [C ABI](../../../../../docs/reference/c-abi.md), the [configuration guide](../../../../../docs/reference/configuration.md) and the [lifecycle guide](../../../../../docs/reference/local-endpoint-lifecycle.md).
