# C-Two 0.7.4: endpoint permissions and connection acquisition

English · [简体中文](0.7.4.zh-CN.md)

This version pairs Python C-Two 0.7.4 with c3 0.3.3 and FastDB 0.2.1.

## Unix endpoint directories

Applications provision their final endpoint directory. Mode `0755` is accepted when the current user owns it and has read, write and traversal access, with no group or other write permission. The default directory uses `0700`. C-Two sets and verifies socket mode `0600` before listening and preserves the application directory and unrelated files.

```python
from pathlib import Path
import c_two as cc

root = Path('/Users/me/Library/Application Support/my-app/ipc')
root.mkdir(parents=True, exist_ok=True, mode=0o755)
cc.set_local_endpoint(root=str(root))
```

Short endpoint names are addressed through an open directory handle, so the configured root supports spaces, Unicode and long paths within filesystem limits. Windows uses current-logon SID Named Pipes and rejects Unix root overrides. See [configuration](../configuration.en.md#local-endpoint-directories) and [lifecycle](../local-endpoint-lifecycle.en.md).

## Connection waiting

```python
proxy = cc.connect(CRM, name='resource', address='ipc://server', timeout=0.1)
```

The timeout is one total connection-acquisition budget, including pool waits, handshake, live route lookup and relay discovery. Omission or `None` adds no caller deadline; zero expires immediately. Negative and non-finite values are rejected. Expiration reports `CallDeadlineExceeded` with `operation=connect`, `transport_phase=pre_dispatch` and `stage`. No resource method has run. Business-call deadlines are configured separately through `cc.with_call_options(...)`; see [connection deadlines](../configuration.en.md#connection-deadlines).

## Persistent routes

Native and generated TypeScript IPC clients query current route authority and retain immutable route/server bindings. They can acquire resources registered after the initial handshake. Old proxies reject removed, replaced or restarted resources; stream recovery does not replay uncertain business calls.

Relay idle eviction releases the data connection while retaining resource registration and owner identity. A route-local acquisition error preserves healthy calls sharing the endpoint. Exhausted IPC fallback retains the original typed IPC cause in error details.

The internal cleanup removes unused pool-announcement codecs, an empty dispatcher allocator parameter and duplicate native outcome projections. Memory fallback tiers and payload lease lifetimes are unchanged.
