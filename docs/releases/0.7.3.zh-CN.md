# C-Two 0.7.3：端点目录

[English](0.7.3.md) · 简体中文

Unix `root` 直接指定最终端点目录。默认目录为 `/tmp/c2-<uidhex>`，自定义目录中的 socket 路径为 `<root>/<32 字符标识>`。标识取逻辑 server id 的 SHA-256 前 128 位，编码为小写十六进制；路径不追加用户目录、版本目录或 `.sock` 后缀。

```python
from pathlib import Path
import c_two as cc

root = Path('/Users/me/Library/Application Support/my-app/ipc')
root.mkdir(parents=True, exist_ok=True, mode=0o700)
cc.set_local_endpoint(root=str(root))
```

自定义目录由应用预建，要求当前用户持有、权限 `0700`。C-Two 初始化默认目录，管理自身端点、租约及协调文件，保留应用目录与无关文件。代码/CLI 优先于进程环境、`.env` 和原生默认值。配置保留中文与空格，查询不访问文件系统，首次本地 I/O 尝试冻结上下文，包括失败尝试。

Linux/macOS 的绑定、连接和存活探测通过已打开的目录句柄访问短名称，完整显示路径不再受 socket 地址字段长度约束；实际目录长度由文件系统打开能力决定。Linux 沿用 `/proc/self/fd`；macOS 在短时独占线程中启动非阻塞连接，再交由调用方异步驱动完成。Node Unix 连接使用同一原生传输，把已连接的描述符移交给 Node。Windows 继续使用当前登录 SID 的 Named Pipe，并明确拒绝 Unix root 配置。

默认和自定义 Unix 目录统一使用既有 schema 3 凭据，保存最终 root 与 namespace id；编码、解码及 CLI 文件读取共用 32 KiB 上限。Windows 保持 kernel-managed schema 1。旧路径派生和 schema 2 默认目录重建直接删除，同一通信组采用匹配构建。已有端点目录与历史文件不做自动迁移或清扫。

身份、路由契约、协调器、租约、incarnation 和精确回收校验继续生效。监听器关闭、原生工作排空和保留载荷释放分别报告。详见[配置指南](../configuration.md)、[生命周期指南](../local-endpoint-lifecycle.md)和[实施设计](../designs/0.7.3-local-endpoint-paths.md)。
