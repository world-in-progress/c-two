# C-Two 0.7.4：端点权限与连接获取

[English](0.7.4.md) · 简体中文

此版本配套 Python C-Two 0.7.4、c3 0.3.3 和 FastDB 0.2.1。

## Unix 端点目录

应用预建最终端点目录。当前用户持有目录，具备读、写、遍历权限，且组和其他用户没有写权限时，允许 `0755`。默认目录使用 `0700`。C-Two 在监听前设置并核实 socket 权限 `0600`，保留应用目录和无关文件。

```python
from pathlib import Path
import c_two as cc

root = Path('/Users/me/Library/Application Support/my-app/ipc')
root.mkdir(parents=True, exist_ok=True, mode=0o755)
cc.set_local_endpoint(root=str(root))
```

短端点名称通过打开的目录句柄寻址，root 支持空格、中文及文件系统允许的长目录。Windows 使用当前登录 SID 的 Named Pipe，拒绝 Unix root 配置。详见[配置](../configuration.md#本地端点位置与平台差异)和[生命周期](../local-endpoint-lifecycle.md)。

## 连接等待

```python
proxy = cc.connect(CRM, name='resource', address='ipc://server', timeout=0.1)
```

timeout 是连接获取的总预算，包含池等待、握手、当前路由查询和 relay 发现。省略或 `None` 不增加调用方总期限；`0` 立即到期；负数和非有限值被拒绝。到期报告 `CallDeadlineExceeded`，details 含 `operation=connect`、`transport_phase=pre_dispatch` 和 `stage`，资源方法尚未执行。业务调用期限通过 `cc.with_call_options(...)` 单独设置，详见[连接期限](../configuration.md#连接期限)。

## 持久路由

原生和生成的 TypeScript IPC 客户端查询当前路由权威状态，固定 route/server 身份，可以取得握手之后注册的资源。旧代理拒绝已删除、同名替换或服务重启后的资源；恢复连接不会重放结果不确定的业务调用。

Relay idle 驱逐释放数据连接并保留资源登记和 owner 身份。单路由获取错误保留共享端点上的健康在途调用。IPC 回退候选耗尽时，错误 details 保留原始 typed IPC cause。

内部精简移除无消费者的池公告 codec、空 dispatcher allocator 参数和重复 native outcome 投影。内存回退层级及载荷租约生命周期保持原有语义。
