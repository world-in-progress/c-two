# Unreleased

Changes since [C-Two 0.12.0 / c3 0.8.0](0.12.0.md) (`f388cc1405ccf36741239ddda6bdeb6ee2e1d408`).

- ADR 0006 adds registration-scoped deduplication and recovery for unary calls with an explicit call ID. Python exposes `cc.with_call_id`, `cc.recover_call` and `cc.query_call`. Codes 721 `CallIdConflict`, 722 `CallResultUnavailable` and 723 `CallOutcomeUnknown` distinguish a conflicting method or input, a confirmed success without a recoverable result and a recovery miss. [ADR 0006](../decisions/0006-post-dispatch-outcome-and-dedup.md), [Python usage](../reference/python-usage.md), [errors](../reference/errors.md)
- ADR 0007 adds bounded call metadata (`CallMetadata`), Host-level admission hooks (`cc.set_server(admission_hook=...)`, Rust `HostOptions::with_admission_hook`), read-only `current_call_context()` inside resource methods and stream steps, and canonical code 724 `AdmissionDenied` (HTTP `403`, `pre_dispatch`, isolated to code 3 at resource callback boundaries). Rust retires `UnaryCallOptions`; Rust, Python (`cc.with_call_options`) and generated TypeScript (`ContractClient.withCallOptions`) all carry reusable view-level `timeout` and `metadata` across unary, keyed, recovery, query, stream and topic operations. [ADR 0007](../decisions/0007-call-metadata-and-admission-hooks.md), [Python usage](../reference/python-usage.md#call-metadata-admission-hooks-and-call-context), [errors](../reference/errors.md#admission-errors)
- IPC 18 adds keyed submission, recovery, an independent query record pair, compact sorted `CallMetadata` on all `OPEN` and `QueryCall` records, server-ACK-only `CAP_ADMISSION_HOOK`, 16-byte `READY (start_seq, head_seq)`, and the `AdmitTopic` / `AdmitTopicResult` record pair. C/FFI ABI 10 exposes keyed operations, recovery, outcome queries and call metadata (`metadata_json` / `options_json.metadata`) to Node and TypeScript. Relay upgrades to **relay mesh 8**, `application/vnd.c-two.topic-stream;version=2` and unified `/_c2/*` data-plane routes, retiring `POST /{route}/{method}` and `POST /{route}/_topics/*`. Upgrade communicating IPC peers, relays and native bindings together, and regenerate TypeScript clients. SHM 4 remains in use. [IPC handshake](../reference/ipc-handshake.md), [C ABI](../reference/c-abi.md), [relay routing](../reference/contracts-and-routing.md#unary-call-outcomes-over-http)
- `HostOptions` configures outcome retention (`outcome_max_entries`, `outcome_max_retained_bytes`) and the Host admission hook (`with_admission_hook` / `without_admission_hook`). `c3 relay` serves all data-plane operations under `/_c2/calls/{call,keyed,recover,outcome}` and `/_c2/topics/{subscribe,confirm}` with `x-c2-meta-*` metadata forwarding and per-subscriber admission on shared topic hubs. [Configuration](../reference/configuration.md), [relay topic forwarding](../reference/contracts-and-routing.md#relay-topic-forwarding)
