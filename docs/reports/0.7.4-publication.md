Both main Windows full jobs passed all 24 gates. Published inventory verification matches all 31 PyPI files and 15 C3 release assets to the tested candidate's names, sizes and SHA-256 values. The Windows `.exe` is directly downloadable. The manifest SHA-256 is `661c14c0e0fb8f6eb354178864d5589eaad465a232c715444e13da74555a0048`.

Actual public macOS ARM64 wheels and C3 passed an isolated Python 3.13 installation check: direct IPC and HTTP relay each transferred 1 MiB, held views and four borrowed inputs were invalidated, and the host, relay and temporary installation directory were cleaned up. The [publication evidence](evidence/0.7.4-publication.json) retains the exact inventory, installation receipt and source-bound run results.

The [FD follow-up](0.7.4-fd-leak-regression.md) confirms no growth with the unchanged downstream probe, real connection regressions, functional negative controls and actual Windows Named Pipe execution. [Astra max's independent evidence audit](../reviews/0.7.4-astra-fd-evidence-audit.md) approved that follow-up with no findings; its historical snapshot predates completion of the broader release gates above.

The original checkout is updated to main and its native extension is rebuilt at 0.7.4. Earlier local documentation drafts remain backed up and in a scoped stash. The implementation worktree is archived, and local and fork branches `socu/0.7.4` are removed. Build cleanup removed 72 paths and increased available disk space by 25,389,998,080 bytes (23.6 GiB), while preserving the usable development environment and original handover files. The deletion list is in the publication evidence. Rust and TypeScript SDKs remain source-only; Windows 11 desktop was not executed.

The Python SDK README, usage and test guides are synchronized by a later documentation commit. Existing 0.7.4 distribution metadata retains the README embedded at publication, including its old 0.7.3 installation text; the repository instructions select 0.7.4. Published artifacts remain bound to the source and hashes above.
