# Managed-v2 Linux acceptance repairs

Base source: `2cfd151949de95c1fd52c2508af8f27dec677a91`. Ubuntu 24.04 run `37495721566` failed both the focused endpoint job and full Core job at the same two c2-local test IDs. Its full Core c2-local result was 77 passed, 2 failed; the retained console is `/tmp/c2-endpoint-implementation-1006/linux-37495721566-failed.log` on the Host machine. This repair changes the managed Unix implementation, its tests, the Rust-owned canonical namespace derivation and expectation, and current-format report pointers.

`managed_bind_never_changes_the_calling_thread_directory` set a private caller directory only on macOS but expected that directory on every target. Linux binds through `/proc/self/fd` and does not have this macOS thread-cwd primitive. The test now preserves macOS's distinct caller-directory assertion and asserts Linux's unchanged process/caller directory before, during, and after two reachable managed binds. The independent subprocess probe starts from an explicit unrelated directory on Linux, without changing the parallel parent harness cwd. Both original test IDs remain.

The original 25-byte marker recorded only device/inode, allowing a removed coordinator inode to be reused after the last descriptor closed. The new 41-byte marker has format version 2 and additionally records a random 16-byte coordinator identity. The gate stores that identity in a bounded 25-byte record, initialized only under its lock when no marker exists and the bounded namespace scan proves no endpoint objects. Existing markers are never rewritten to adopt another gate. A listener retains a descriptor to the original gate until its lease ownership ends, including failed close/drop paths; the namespace still explicitly releases its flock, so this descriptor pins the OS object without extending the coordinator lock.

This is a deliberate 0.x format cut for the unreleased internal rendezvous format. Rust `c2-config` now derives ManagedV2 solely as `/tmp/c2-<effective-uid-hex>/v2.2/<sha256(server-id)>.sock`; the protocol enum and string `managed-v2` remain unchanged. Owner records retain protocol byte 2 and now use record-format byte 2. The old `/v2` root is never probed, read, migrated, adopted, or deleted, so an old experimental participant cannot share the new coordinator. Existing macOS global managed roots and legacy history were preserved. A version 1 device/inode-only marker injected into a private new-format namespace returns `Unverified(CoordinatorReplaced)` and bind refuses with `AddrInUse`, leaving the gate and marker unchanged. This patch supplies no online migration and does not infer inactivity from an unlocked gate.

The existing replaced-gate test now deterministically models inode ABA by updating only device/inode fields to describe a replacement gate while retaining the original persistent identity. This fails against the base implementation even on macOS, where natural inode reuse did not occur: `/tmp/c2-managed-linux-fail-first.log`, exit 101, failure at the added assertion. After the implementation change the same test passed: `/tmp/c2-managed-linux-gate-green.log`. The final test also rejects a well-formed replacement gate with a different nonce and matching marker device/inode. Additional tests prove the unlinked original gate stays pinned while a live listener owns its lease, replacement never creates a second successful listener, failed retirement releases the lease, and a version 1 marker is rejected without mutation.

Verification used exclusive `CARGO_TARGET_DIR=/tmp/c2-endpoint-targets/managed-linux-boundaries`, on macOS. Before the namespace cut, a wider managed selection passed 22 and failed 5 public/global cases because this machine's preserved global `/v2` namespace had an old version 1 marker: `/tmp/c2-managed-linux-focused-mac.log`. Subsequent isolated selections passed 22 managed cases and 2 scoped sweep cases, retained in `/tmp/c2-managed-linux-isolated-mac.log` and `/tmp/c2-managed-linux-scoped-mac.log`. These limited selections were interim evidence only. After the Host approved the canonical `/v2.2` format root, complete `cargo test --manifest-path core/Cargo.toml -p c2-local --lib` passed 81/81, 0 ignored and 0 filtered, including all public namespace, concurrency, registered-child exit, independent cwd subprocess, and original two failure IDs: `/tmp/c2-managed-linux-full-focused-mac.log`. The exact c2-config `local::tests` selection passed 5/5: `/tmp/c2-managed-linux-config-mac.log`. Existing ID preservation and the two additional tests account for 79 -> 81 c2-local tests.
