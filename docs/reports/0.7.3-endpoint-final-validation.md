Existing permission, namespace, nonce, listener-lease, incarnation, route-contract and exact-inode cleanup checks remain in force.

Real native tests cover 128, 256, 512 and 768 UTF-8-byte directories with Chinese characters and spaces, IPC round trips, inspection, restart, OS-confirmed child termination and exact reap/scoped sweep. Node adopts a descriptor from the same native Unix connection path. The 15-connection/4-listener long-directory test covers actual streams, closing the context during pending work, connector disposal and repeated fd close.
