## Behavior verified

The configured Unix root is the final endpoint directory. Endpoint names are 32 lowercase hexadecimal characters with no socket suffix or extra UID/layout directories. Linux/macOS bind, connect and maintenance probes use an opened directory and a short kernel pathname; the descriptive absolute pathname does not consume the Unix socket address capacity. Existing permission, namespace, nonce, listener-lease, incarnation, route-contract and exact-inode cleanup checks remain in force.

Real native tests cover 128, 256, 512 and 768 UTF-8-byte directories with Chinese characters and spaces, IPC round trips, inspection, restart, OS-confirmed child termination and exact reap/scoped sweep. The application directory and unrelated files survive cleanup. Additional Python, Node and CLI tests exercise directories of at least 512 bytes. macOS pending-connect completion, cancellation and refusal use a genuinely full listener backlog, require `PENDING_CONNECT_VERIFIED` from the child and check descriptor counts; process and caller-thread working directories remain unchanged.

Node adopts a descriptor from the same native Unix connection path. The 15-connection/4-listener long-directory test covers actual streams, closing the context during pending work, connector disposal and repeated fd close. Windows continues through current-logon Named Pipes and rejects Unix root configuration.
