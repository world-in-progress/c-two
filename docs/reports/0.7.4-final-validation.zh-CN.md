## Relay 容量响应

容量拒绝在业务准入前确定。无 Expect 且长度声明有效时，handler 按帧丢弃传输数据，受声明长度及单一 2 秒期限约束；不聚合或解码整包、不调用资源、不重新准入。拒绝上传 B 收尾期间，即使 A 释放容量，也不能准入 B。被拒绝的 Expect 与未知长度 body 不读取；读取错误、长度不符或超时保留原拒绝。

真实 SDK 门禁中的合法完整 eager 上传收到 canonical HTTP 502 / code 717 / envelope `pre_dispatch`，业务 callback 为零。错误或不完整传输若阻止响应到达客户端，既有 wrapper 可报告 `DispatchUncertain`；服务端拒绝决定不能证明客户端已收到它。没有新增全局拒绝 handler 并发上限；native forwarding drain 也不代表全部 HTTP 缓冲的屏障。详见[配置指南](../configuration.md)。
