## Registration retirement fence

Ordinary `/_unregister` now requires the original name, server_id, server_instance_id, route_uid, and route_revision. Relay authority compares all fields under the route-table write lock, then reuses unregister_local_route_if_matches. A newer registration is preserved with a Superseded result; an exact repeated target is idempotent. Successful captured-target metadata is local-only and retires with its existing tombstone GC; IPC selection, gossip wire, endpoint v2 algorithms, and business-route contract lookup were not changed.

Core saves the token before native commit can expose the route, including the final relay publish wait window. The shutdown caller captures the concrete Server's original scope set before spawning its transaction; asynchronous cleanup uses that captured set and never queries a later Runtime or relay route for a replacement token. Native direct projections may capture an unrecorded token from the native catalog only at this initial retirement boundary. Ordinary teardown refuses a missing scope instead of falling back to name-only removal. The historical name/server-id operation is now the independent `/_admin/unregister` endpoint and RelayControlClient.admin_unregister.
