## 1. Relax permissions for custom Unix endpoint roots

Keep `0700` for the default directory. Allow modes such as `0755` for an application-provided final directory: the current user owns it and has the required read, write and search access, while other users cannot modify its entries. The application creates the directory; C-Two manages its own endpoint files inside it.

Version 0.7.3 requires exactly `0700` and sets socket permissions to `0600` after listening starts. Relaxing the directory check also requires changing that order to avoid a connection window under a permissive `umask`. Source: [directory checks](../../core/transport/c2-local/src/unix_common.rs), [listener initialization](../../core/transport/c2-local/src/unix_managed.rs).

Implementation:

- [ ] Keep default-directory creation at `0700`. Validate custom-directory ownership, effective access and protection against writes by other users; accept `0755`. Preserve final-directory semantics without chmodding application directories, adding private subdirectories or adding layout versions.
- [ ] Initialize sockets in this order: bind, set and verify `0600`, then listen. Keep coordinator and lease files restricted. On permission or listen failure, remove only objects created by this attempt whose identity still matches. Do not change the host application's process-wide `umask`.
- [ ] Apply the same directory rules to bind, connect, probe, inspect, reap and sweep. Retain directory descriptors, file identity, leases and replacement checks. Preserve application directories and unrelated files during cleanup.
- [ ] Report the directory path, observed ownership/permissions and failed requirement. Do not collapse permission failures into a generic unverifiable-namespace or address-in-use error.
- [ ] Retain Windows current-logon SID access policy and kernel listener leases. Keep Unix permission assumptions out of shared interfaces and error projections.
- [ ] Update both language editions of the configuration and lifecycle guides when implemented. Update package versions and publication status through the release workflow.

Acceptance:

- [ ] On Linux/macOS, exercise real IPC, restart and maintenance with default `0700` and custom `0755` directories, including long paths, spaces and Chinese characters. Preserve application directory permissions.
- [ ] Reject directories writable by other users, foreign ownership, final-directory symlinks and identity replacement with specific diagnostics. Preserve existing listeners and unrelated files.
- [ ] Use permissive `umask` values in isolated child processes to prove sockets have `0600` before listening. Exercise permission-setting and listen failures, cleanup, and rejection of connections by other ordinary users. Record the platforms and cross-user checks actually executed.
- [ ] Run focused coverage for affected Python/Rust, Node/FFI, c3 and relay entry points, exact reap, scoped sweep, duplicate binds and normal shutdown. Use Windows CI to check that shared changes preserve existing endpoint behavior.
