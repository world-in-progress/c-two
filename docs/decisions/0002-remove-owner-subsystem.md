# 删除所有者子系统

状态：已采用（2026-11-01）。

删除 `OwnerBound` 生命周期、所有者监督与缺席宽限、恢复凭证与接管、托管子进程，以及 IPC 里所有者控制这种连接角色（0x16 帧）。标准是维护者定的："下游看不见、内部机制也不需要，就可以删。"已知下游（hey-my-buddy、toodle、一个水文模拟后端）都没有用它，hey-my-buddy 评估后明确不采用；C ABI、CLI、relay 与端点维护都不依赖它（独立评估与复核）。普通 Host 共用的关闭、生命周期观测、准入锁与代次、端点凭据保留。

失去的能力：控制方失联后自动停服，以及凭票据互斥接管同一个 Host。以后真有使用者，在单一属主的连接模型上重新设计，不恢复旧协议。

依据：[接口审查](../design/2026-10-31-api-surface-review.md)第六节、[协议批详细设计](../design/2026-11-01-protocol-batch-design.md)第五节。
