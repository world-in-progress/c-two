## 合并时了结的待办

- "要核实的事"里 TS 传输不处理 SIGNAL 帧一项：它的前提随自动心跳一起删除了。服务端不再主动发 PING，它发出的 SIGNAL 帧只有对客户端 PING、SHUTDOWN 与 DISCONNECT 的回复；`ping_server_endpoint` 是服务端去探测别的端点。这是按代码核对的，没有运行复现。
- "待用户决定"里单一属主的决定 2、3：详细设计把两者收缩为低层未消费 carrier、原始远端读区间与在途借出的安全约束，不再约束 SDK hold，随设计于 2026-11-01 批准。
- Core 与 Python 区的顺带项"`c2-core/src/control.rs` 每次克隆上下文"：P6 已改为借用。
- 协议批一项里仍开着的子项留在待办：暂不暴露的写死数值移到"不排期"；`max_total_chunks` 的待定并入流式 RPC 一项里分片的结构调整（B2）；relay 连接池的测试用连通状态覆盖移到按区域结构调整的 relay 区；发版时改 README 里的版本说明单列为一项。
